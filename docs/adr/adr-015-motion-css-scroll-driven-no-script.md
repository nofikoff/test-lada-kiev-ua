# ADR-015: движение только на CSS, проявление и шапка — на таймлайнах прокрутки, уровень один

## Context

Редизайн требовал проявления блоков при въезде в кадр, уплотнения шапки при прокрутке и заметного фонового движения — без прироста исполняемого кода. Владелец выбрал на прототипе самый заметный из четырёх уровней движения. Принято в пакете 002.

## Decision

`animation-timeline: view()` / `scroll()` внутри `@supports`, вложенного в `@media (prefers-reduced-motion: no-preference)`; исходное состояние элементов видимое. Уровень движения зашит один, тише — только по системному `prefers-reduced-motion`.

## Consequences

- Отвергнуто: `IntersectionObserver` — около 400 Б кода и тот же отказ без скриптов: скрытые до наблюдения блоки не появятся никогда.
- Отвергнуто: обработчик `scroll` для шапки — код и дрожание на частых событиях.
- Отвергнуто: переключатель интенсивности движения в интерфейсе.
- Около 13% посетителей (caniuse, 2026-09-06) видят страницу без проявлений и с постоянно плотной шапкой — это штатное поведение.
- Порядок вложенности и прочие правила — [docs/specs/motion.md](../specs/motion.md).
- Обработчик `scroll` в `Gallery.astro` (пакет 003) не анимирует: он ведёт состояние кнопок ленты.
