# ADR-012: проверки идут против собранного `dist/`, а не против компонентов

## Context

Требования сайта сформулированы про опубликованный файл: что получает поисковик, какие адреса отвечают, что видно без скриптов. Редизайн опирается на CSS, чья поддержка в WebKit самая свежая. Принято в пакете 001, второй движок — в 002.

## Decision

Playwright против `astro preview` над `dist/` (`playwright.config.ts`, порт `PREVIEW_PORT`); проекты `desktop` и `mobile` на Chromium плюс `webkit`, проверки `@build` читают `dist/` одним проектом.

## Consequences

- Отвергнуто: модульные тесты компонентов — уверенность в разметке компонента, но не в том, что попало в опубликованный файл.
- Отвергнуто: прогон в одном Chromium — анимации по таймлайну и `initial-letter` там давно стабильны, и проверка их там не проверяет ничего. WebKit удлиняет прогон примерно в полтора раза и требует `npx playwright install webkit`.
- Прогон без свежей сборки проверяет прошлое состояние и выглядит необъяснимо зелёным. Прогон против `astro dev` — тоже: поэтому у preview свой порт.
- Firefox не автоматизирован; целостность страницы без таймлайнов в нём проверялась ручным проходом 2026-09-07.
