# ADR-011: счётчик GA4 загружается как до миграции, без отложенной загрузки

## Context

После снятия фреймворка счётчик `G-WZT8TJLSDP` — самый тяжёлый скрипт страницы (174 КБ сжатыми, замер 2026-09-06), и его хочется отложить ради LCP. Результат миграции оценивается по той же статистике. Принято в пакете 001.

## Decision

Сниппет `gtag` стоит в `BaseLayout.astro` `is:inline`, с тем же идентификатором и тем же способом загрузки; из бюджета исполняемого кода он исключён (`scripts/analyze-bundle.mjs`).

## Consequences

- Отвергнуто: отложенная загрузка счётчика (по событию, после `load`, через partytown) — теряет визиты ушедших в первые секунды, и статистика до и после перестаёт быть сопоставимой.
- Сниппет — чужой код и не переписывается: `prefer-rest-params` для него снят в `eslint.config.js`, потому что gtag.js читает из `dataLayer` объект `arguments`, а не массив. Анализатор бюджета узнаёт его по самому сниппету, а не по вызову `gtag(` — собственные события сайта в бюджет входят.
