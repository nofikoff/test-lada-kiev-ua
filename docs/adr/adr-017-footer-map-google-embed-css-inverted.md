# ADR-017: карта в подвале — встроенный кадр Google под CSS-инверсией

## Context

После редизайна светлая карта Google выбивалась из тёмной палитры. Ключа Maps API у проекта нет, новых сетевых запросов и платных сервисов быть не должно. Принято в пакете 002, решение владельца 2026-09-06.

## Decision

Кадр Google остаётся как есть; тёмный вид даёт `filter: invert(0.92) hue-rotate(180deg) saturate(0.6)` на нём (`Footer.astro`).

## Consequences

- Отвергнуто: собственная статичная схема со ссылкой на карты — теряются интерактив и карточка места.
- Отвергнуто: стилизованная карта через Maps JavaScript API — ключ, квота и исполняемый код.
- Риск принят владельцем: условия Google Maps Platform запрещают «препятствовать полному отображению» карты; прямого запрета фильтров нет.
- WebKit 2026-09-07: кадр под фильтром остаётся интерактивным, подписи улиц читаются. Если жесты сломаются — запасной путь первый из отвергнутых.
