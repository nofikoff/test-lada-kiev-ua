# ADR-007: тексты категорий — Markdown, словарь интерфейса — TypeScript `as const`

## Context

Кроме прайса ([ADR-006](adr-006-prices-single-json-group-defines-category.md)) у сайта два вида текста: многоабзацная проза двенадцати страниц категорий и короткие подписи интерфейса на трёх языках. Встроенного механизма переводов у Astro нет — формат выбираем сами. Принято в пакете 001.

## Decision

Страница категории — `src/content/services/<locale>/<category>.md` через `glob()`. Словарь — `src/i18n/ui.ts`, объект `as const`, тип выводится из украинской локали.

## Consequences

- Отвергнуто: тексты категорий в JSON — проза становится одной строкой с экранированными переводами строк, вычитка и правка дорожают.
- Отвергнуто: словарь в JSON — пропущенный ключ другого языка отдаёт `undefined` и виден только на собранной странице; в TS он ошибка `astro check`.
