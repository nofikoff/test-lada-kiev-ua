# ADR-021: отдельных страниц под поисковые запросы нет

- **Related:** [docs/specs/page-head.md](../specs/page-head.md) §Целевые запросы · [docs/specs/routes.md](../specs/routes.md)

## Context

Пакет 004 усилил тексты под запросы вроде «шугаринг Київ» и «пудрові брови Київ». Для каждого такого запроса напрашивается своя страница (`/sugaring/`, `/powder-brows/`); запросы выбраны без статистики Search Console.

## Decision

Запрос обслуживает существующая страница категории: он стоит в её `<title>`, `<h1>`, описании и первом абзаце; новых адресов под запросы не заводится.

## Consequences

- Positive: пятнадцать адресов и карта сайта не меняются; нет тонких страниц, повторяющих текст категории.
- Negative: узкий запрос конкурирует с остальным содержанием страницы категории.
- Отвергнуто: страница на запрос — новые адреса в `routes.md`, карте сайта и `.htaccess`, а на каждую ещё 400 неповторяющихся слов на трёх языках; при запросах, выбранных без статистики, это расход без измеримой цели. Вернуться — когда данные Search Console покажут спрос, который страница категории не забирает.
