# ADR-006: прайс — один `prices.json`, категория выводится из группы

## Context

Прайс показывается в двух группировках: вкладки главной (массаж тела, экзотика, депиляция, бьюти с перманентом внутри) и четыре страницы категорий (массаж, депиляция, перманент, бьюти). Цена должна меняться в одном месте на всех языках. Принято в пакете 001.

## Decision

Один массив `src/data/prices.json` с явным `id` у записи, загрузчик `file()`. У позиции есть поле `group`, категория выводится из группы (`src/data/price-groups.ts`), вкладки — конфигурация поверх групп (`src/i18n/tabs.ts`) без единой цены.

## Consequences

- Отвергнуто: файл на язык (`prices.uk.json` …) — списки позиций расходятся по составу, а не только по переводу.
- Отвергнуто: коллекция на категорию через `parser` — четыре определения там, где хватает одного поля.
- Отвергнуто: объект-карта вместо массива — порядок ключей становится неявной договорённостью, а порядок в файле и есть порядок отображения.
- Правила данных и две ловушки загрузчика — [docs/specs/content-model.md](../specs/content-model.md).
