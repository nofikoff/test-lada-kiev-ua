# ADR-001: лента фото — CSS scroll-snap без автопрокрутки

## Context

Главной нужна лента из 11 фото Лады ([spec 003](../../specs/003-lada-photos-home/spec.md)). Действуют бюджет исполняемого кода 1.5 КБ на страницу, из них сегодня занято 560 Б, и доступность 100. Слайдер с автопрокруткой — вариант, который предлагают первым.

## Decision

Горизонтальная лента на `scroll-snap-type`, без автопрокрутки. Кнопки «назад/вперёд» — собственный скрипт около 0.5 КБ, прогрессивное улучшение поверх ленты, которая листается и без него.

## Consequences

- Слайдер-библиотека (Swiper и подобные) отвергнута: десятки КБ JS против потолка 1.5 КБ.
- Автопрокрутка отвергнута. По WCAG 2.2.2 движущемуся содержимому нужна пауза. К тому же автопрокрутку дальше первых кадров почти не смотрят.
- Мозаика отвергнута: 11 фото сеткой удлиняют главную, а автор просил ленту.
- Без скриптов лента работает целиком. Скрипт добавляет только кнопки и событие аналитики.
- Добавить фото — значит добавить запись в `src/data/gallery.json`. Разметку и скрипт при этом трогать не нужно.
