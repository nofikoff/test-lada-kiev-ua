# ADR-004: статический сайт на Astro без UI-фреймворка на клиенте

## Context

До 2026-09-06 сайт был SPA на Vite + React: поисковик получал пустой каркас, исполняемого кода было 75 КБ сжатыми помимо аналитики. Нужны HTML с контентом, прайс как данные с проверкой на сборке и оптимизация картинок. Принято в пакете 001.

## Decision

Astro 7, `output: 'static'`, ни одного UI-фреймворка в клиентской сборке.

## Consequences

- Отвергнуто: Vite + React с пререндерингом (`vite-plugin-ssr`, `react-snap`) — HTML появляется, но рантайм фреймворка остаётся, а данные, картинки и маршрутизацию языков закрывать нечем.
- Отвергнуто: Next.js со статическим экспортом — возвращает React обязательной зависимостью.
- Отвергнуто: Eleventy / Hugo — нет типизированных коллекций с валидацией и встроенной оптимизации изображений, часть требований ушла бы в самописные скрипты.
- Интерактив пишется средствами платформы ([ADR-005](adr-005-native-details-menu-inline-tab-script.md)); бюджет исполняемого кода держит `scripts/analyze-bundle.mjs`.
