# ADR-008: адреса — `build.format: 'directory'`, категории латиницей одинаково во всех языках

## Context

Действующие адреса `/`, `/ru`, `/en` стоят во внешних ссылках и меняться не могут. Сайт — статические файлы на Apache. Появляются двенадцать страниц категорий в трёх языках. Принято в пакете 001.

## Decision

Сборка выдаёт `<путь>/index.html`, `/ru` приходит на `/ru/` перенаправлением `DirectorySlash`, канонический адрес всегда со слешем. Адрес категории — латинское значение категории, одинаковое во всех локалях: `/massage/`, `/ru/massage/`, `/en/massage/`.

## Consequences

- Отвергнуто: `build.format: 'file'` (`ru.html`) — адрес `/ru` тогда требует `MultiViews` или правил перезаписи, то есть корректность адресов уезжает в конфигурацию сервера.
- Отвергнуто: локализованные адреса категорий — соответствие языковых версий пришлось бы держать таблицей; с единым адресом оно вычисляется подстановкой префикса (`languageAlternates` в `src/i18n/paths.ts`).
- Отвергнуто: динамический `[lang]` — при `prefixDefaultLocale: false` основной язык всё равно живёт отдельным файлом, и вышли бы две механики для трёх одинаковых страниц.
- Контракт адресов — [docs/specs/routes.md](../specs/routes.md).
