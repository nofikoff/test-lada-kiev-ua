# ADR-002: портрет первого экрана — колонкой, а не фоном во всю ширину

## Context

Стоковый кадр первого экрана заменяется портретом Лады, вертикальным 1440×1800 ([spec 003](../../specs/003-lada-photos-home/spec.md)). Раскладка из spec 002 кладёт фото фоном на весь экран, а текст слева на плотную статичную подложку (FR-017 из 002).

## Decision

На широком экране портрет стоит отдельной колонкой справа от текста, на узком — блоком над текстом.

## Consequences

- Фон во всю ширину отвергнут. Вертикальный кадр, обрезанный под широкий экран, ставит лицо по центру, то есть под подложку текста. Вдобавок 1440 px растягиваются на 1920+ с потерей резкости.
- Текст поверх фото на телефоне отвергнут: текстовая колонка занимает больше половины высоты экрана и закрыла бы лицо.
- Монограмма уходит с первого экрана. Разреженный правый край, который она заполняла (FR-018 из 002), теперь занимает портрет.
- Ширина колонки портрета ограничена половиной ширины исходника при плотности 2x. Исходник крупнее 1440 px — повод пересмотреть это ограничение, а не раскладку.
- На телефоне портрет становится элементом LCP. Поэтому раскрытие из затемнения делает накрывающий слой, а не прозрачность изображения.
