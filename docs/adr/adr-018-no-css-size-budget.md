# ADR-018: у стилей нет порога размера, порог — результат Lighthouse

## Context

Редизайн добавлял сквозной фон, keyframes и токены: по оценке 4–6 КБ к 16.7 КБ стилей (2026-09-06). Исполняемый код уже имеет жёсткий порог в `scripts/analyze-bundle.mjs`. Принято в пакете 002.

## Decision

Размер CSS не нормируется. На критический путь стили влияют через LCP, а LCP меряется напрямую.

## Consequences

- Отвергнуто: числовой порог CSS поверх LCP — второй критерий к той же величине, обосновать его число нечем.
- Рост стилей виден только в LCP: на `/` и `/ru/` он стоит на 2.48 с при пороге 2.5 ([docs/specs/home-hero.md](../specs/home-hero.md) §Производительность).
