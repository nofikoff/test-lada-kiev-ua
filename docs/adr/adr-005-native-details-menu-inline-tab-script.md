# ADR-005: меню на `<details>`, вкладки прайса — встроенный скрипт с ARIA

## Context

Без UI-фреймворка ([ADR-004](adr-004-static-astro-no-client-framework.md)) мобильному меню и вкладкам прайса нужны работа с клавиатуры, объявление состояния и полный контент при отключённых скриптах. Принято в пакете 001.

## Decision

Меню — `<details>`/`<summary>`. Вкладки — модуль в `<script>` компонента `PriceTabs.astro` с `role="tablist"`, `aria-selected`, `aria-controls`, стрелками, Home и End; в разметке все панели видимы, неактивные скрывает скрипт при инициализации.

## Consequences

- Отвергнуто: вкладки на `:target` — меняют адрес страницы и ломают канонический адрес.
- Отвергнуто: вкладки на скрытых радиокнопках — неверная семантика для вспомогательных технологий.
- Обратный порядок (панели скрыты в разметке, скрипт их открывает) оставляет посетителя без скриптов с пустым прайсом, и остальной прогон этого не видит. Держит `tests/no-script.spec.ts`.
