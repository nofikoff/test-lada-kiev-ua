# ADR-009: шрифты — Astro Fonts API с отдачей со своего домена

## Context

До 2026-09-06 гарнитуры грузились ссылкой на Google Fonts: два сторонних домена в критическом пути загрузки. Кириллица с украинскими знаками обязательна. Принято в пакете 001.

## Decision

`fonts` в `astro.config.mjs`, провайдер `fontProviders.google()`: файлы скачиваются на сборке и отдаются с собственного домена, подмножества `latin` и `cyrillic`.

## Consequences

- Отвергнуто: ссылка на Google Fonts — два установления соединения до первой отрисовки текста.
- Google отдаёт переменный файл на подмножество, объявленный несколькими `@font-face`; Astro запоминает у элемента предзагрузки начертание первого правила. Отбор предзагрузки по начертанию поэтому не находит ничего и молча оставляет страницу без неё — отбирать только по подмножеству (`BaseLayout.astro`).
- Наличие украинских знаков проверяется рендером, а не списком файлов: `tests/fonts.spec.ts`.
- Выбор гарнитуры заголовков — [ADR-014](adr-014-heading-typeface-cormorant.md).
