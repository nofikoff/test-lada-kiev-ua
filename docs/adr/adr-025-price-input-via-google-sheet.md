# ADR-025: Price amounts entered in a Google Sheet

- **Related:** [ADR-006](adr-006-prices-single-json-group-defines-category.md) · [ADR-024](adr-024-articles-published-via-git-no-cms.md) · [ADR-026](adr-026-single-ci-deploy-path.md) · [docs/specs/content-model.md](../specs/content-model.md)

## Context

Цены меняет Лада, технически не подготовленная. До 2026-10-12 любую сумму в `src/data/prices.json` правил и выкладывал только автор. Ладе нужно менять суммы самой, а состав, порядок, названия и переводы позиций остаются за репозиторием.

## Decision

Суммы вводятся в Google-таблицу на личном Google автора: одна строка — одна сумма, Лада — редактор с правом только на ячейки сумм и галочку «Опубликовать». Источником сборки остаётся `prices.json`, публикация пишет в него только суммы.

## Consequences

- Positive: Лада работает в знакомом интерфейсе с телефона; учётная запись GitHub и свой код на сервере не нужны.
- Positive: схема коллекции и все гейты проверяют суммы так же, как правку автора; история цен остаётся в git.
- Negative: сумму в `prices.json` больше нельзя править руками — публикация остановится на конфликте. Правку структуры прайса сопровождает перестройка таблицы (`mode: rebuild-sheet`).
- Negative: таблица, скрипт таблицы и PAT — три внешних объекта, которых нет в репозитории; их настройка описана в `docs/runbook-deploy.md`.
- **Rejected: git-based CMS (Sveltia, Decap) на `/admin`.** Ладе нужна учётная запись GitHub, интерфейс англоязычный, а форма из 73 позиций с вложенными вариантами тяжела для нетехнического человека.
- **Rejected: своя админка на сервере.** PHP, авторизация, защита от перебора и поверхность атаки на проде ради 110 чисел — всё то, что таблица даёт без кода.
- **Rejected: публикация сама после правки, по таймеру или по расписанию.** Недоправленный прайс уходит на сайт посередине, а workflow по расписанию в публичном репозитории GitHub отключает после 60 дней без активности.
- **Rejected: суммы во входных данных запуска вместо чтения таблицы из CI.** Проверки и обратная связь уехали бы в скрипт таблицы вне тестов, а утёкший токен позволял бы публиковать произвольные суммы.
