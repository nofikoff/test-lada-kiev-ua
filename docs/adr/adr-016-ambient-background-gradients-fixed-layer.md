# ADR-016: сквозной фон — один фиксированный слой на радиальных градиентах

## Context

Редизайн добавил фон из дышащих пятен света, кривых, частиц и зерна. Мобильный профиль Lighthouse — главный судья производительности, бюджет исполняемого кода на анимацию нулевой. Принято в пакете 002.

## Decision

Один слой `position: fixed` под всем содержимым (`Ambience.astro`), пятна — `radial-gradient` с прозрачным краем, анимируются только `transform` и `opacity`; зерно — `feTurbulence` в SVG `data:`-URI.

## Consequences

- Отвергнуто: сплошной круг под `filter: blur()` — внеэкранный буфер и размытие на каждый кадр, первое, что просаживает мобильную оценку.
- Отвергнуто: пятна внутри каждой секции — секция снова замкнутый прямоугольник, число анимируемых слоёв растёт с числом секций.
- Отвергнуто: Canvas или WebGL — исполняемый код при нулевом бюджете.
- Отвергнуто: PNG-тайл зерна — лишний запрос и файл при том же результате.
- Цвета пятен — только из палитры: розовое и янтарное пятна прототипа не перенесены, акцент один ([docs/specs/design-tokens.md](../specs/design-tokens.md)).
