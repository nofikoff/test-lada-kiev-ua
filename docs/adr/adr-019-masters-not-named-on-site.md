# ADR-019: мастера студии, кроме Лады, по именам на сайте не называются

- **Related:** [docs/specs/voice.md](../specs/voice.md)

## Context

Сайт говорит «ми» от лица студии Лады Новиковой; тексты массажа уже подразумевают нескольких мастеров (масаж у чотири руки, виїзд майстра). Вопрос, называть ли их, решал автор в brainstorming пакета 004, 2026-09-27.

## Decision

По имени на сайте называется только Лада; остальные — команда («наші майстри»), без имён, фото и направлений.

## Consequences

- Positive: смена состава команды не требует правки сайта; не нужны данные и согласие каждого мастера на публикацию.
- Negative: посетитель не может выбрать мастера на сайте — только при записи по телефону.
- Отвергнуто: карточки мастеров с именем, направлением и фото — объём данных от Лады, согласие мастеров и правка сайта при каждом изменении состава.
