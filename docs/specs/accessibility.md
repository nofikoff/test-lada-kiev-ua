# Доступность

Цель — 100 в Lighthouse на мобильном профиле на `/`, `/ru/`, `/en/` (достигнута 2026-09-07, держится на 2026-09-27 — [home-hero.md](home-hero.md) §Производительность). Принято в пакетах 001 и 002.

| Требование | Где держится |
|---|---|
| Контраст текста к своей подложке ≥ 4.5:1 в покое, при наведении и при фокусе, без послабления для крупного текста; основной и вторичный текст ≥ 7:1 по палитре | `tests/contrast.spec.ts`, пары — [design-tokens.md](design-tokens.md) |
| Главная кнопка — латунь с угольным текстом, ≥ 7:1 | `.btn-primary` в `src/index.css` |
| Своё видимое состояние фокуса у каждого фокусируемого элемента; кольцо браузера по умолчанию на угле не гарантировано | `:focus-visible` в `src/index.css` |
| Область нажатия переключателей прайса ≥ 24×24 px после отказа от кнопочной заливки | `tests/typography.spec.ts` |
| Ровно один `h1`, уровни заголовков не перескакивают | `tests/headings.spec.ts` |
| Меню и вкладки прайса управляются с клавиатуры (стрелки, Home, End) и объявляют состояние | `tests/interaction.spec.ts`, [ADR-005](../adr/adr-005-native-details-menu-inline-tab-script.md) |
| Без скриптов виден весь прайс, меню раскрывается, переходы работают | `tests/no-script.spec.ts` |
| Уменьшенное движение — ни одной действующей анимации, положения блоков неизменны | `tests/reduced-motion.spec.ts`, [motion.md](motion.md) |
| Порядок в разметке совпадает с визуальным порядком первого экрана | [home-hero.md](home-hero.md) §Разметка |

## Не измеряется

- Контраст раскрытого мобильного меню: `contrast.spec.ts` меню не раскрывает.
- Сдвиг макета при отказе загрузки шрифтов: замеренный CLS относится к обычной подмене гарнитуры.
- Длина строки на ширине 360 px: `typography.spec.ts` меряет 1440 и 2560; на узком экране ширину задают поля, и строка может стать только короче.
