# Заголовочная часть страницы

Что обязана содержать каждая страница сайта. Реализация — `src/components/SeoHead.astro`, у страниц ошибки — `src/components/ErrorHead.astro`. Проверка — `tests/seo-contract.spec.ts` по собранному HTML: требование относится к опубликованному файлу. Машиночитаемое описание — [structured-data.md](structured-data.md). Принято в пакете 001, 2026-09-06.

## Состав

| Элемент | Правило |
|---|---|
| `<html lang>` | `uk`, `ru` или `en`. Код `ua` — код страны и не употребляется нигде, где ожидается язык |
| `<title>` | на языке страницы; пара «заголовок + описание» уникальна по всему сайту |
| `description` | на языке страницы, 120–160 знаков |
| `canonical` | абсолютный, с `www`, в форме со слешем ([routes.md](routes.md)) |
| `hreflang` | три ссылки, включая себя, плюс `x-default` на украинскую версию; у подстраницы — две, uk и ru; у страницы базы знаний — по существующим версиям (§Языковые альтернативы) |
| Open Graph | тип, адрес, заголовок, описание, изображение с размерами, локаль, альтернативные локали, имя сайта |
| Twitter | тип карточки, заголовок, описание, изображение |
| Аналитика | счётчик `G-WZT8TJLSDP` в прежнем виде — [ADR-011](../adr/adr-011-analytics-snippet-unchanged-not-deferred.md) |

Изображение превью с 2026-09-27 собирается из портрета и меняет адрес вместе с ним — [home-hero.md](home-hero.md) §Превью ссылок и JSON-LD.

`og:type` — `website` на всех страницах, статьи базы знаний тоже. Отвергнуто: `article` с `article:published_time` расширяет заголовочную часть ради поля, которого не требовало ни одно требование. Даты статьи несёт JSON-LD ([structured-data.md](structured-data.md) §Knowledge base).

## Языковые альтернативы

Страница категории ссылается на ту же категорию в других языках, а не на главную. Соответствие вычисляется подстановкой префикса — [ADR-008](../adr/adr-008-urls-directory-format-latin-category-slugs.md).

```
/massage/   → uk: /massage/  ru: /ru/massage/  en: /en/massage/  x-default: /massage/
/ru/beauty/ → uk: /beauty/   ru: /ru/beauty/   en: /en/beauty/   x-default: /beauty/
```

Подстраница услуги ([ADR-028](../adr/adr-028-commercial-service-subpages.md)) называет только свои языки из реестра `serviceSubpages` (`src/data/subpage-registry.ts`): английской версии нет, а английская категория ей не эквивалент. Так же устроен `og:locale:alternate` — только второй язык подстраницы. Переключатель языка в шапке на всех страницах ведёт на главную выбранного языка, а не на ту же страницу: `<a hreflang>` переключателя — не языковая альтернатива.

```
/depilation/sugaring/ → uk: /depilation/sugaring/  ru: /ru/depilation/sugaring/  x-default: /depilation/sugaring/
```

Страница базы знаний и страница эксперта ([ADR-029](../adr/adr-029-knowledge-base-collection-links-from-seo-map.md)) несут свой набор языков: `hreflang` и `og:locale:alternate` строятся по тем версиям, для которых есть файл в `src/content/guide/` (у эксперта — в `src/content/expert/`), а не по списку языков сайта. `x-default` — uk, а при её отсутствии единственная существующая версия. Страница на одном языке поэтому ссылается только на себя; в карте сайта у неё альтернатив нет ([routes.md](routes.md)). Английской версии у раздела нет, как у подстраницы.

```
/guide/depilation/vs-epilation/    → uk: /guide/depilation/vs-epilation/  ru: /ru/guide/depilation/vs-epilation/  x-default: /guide/depilation/vs-epilation/
/guide/depilation/aftercare/ (uk)  → uk: /guide/depilation/aftercare/  x-default: /guide/depilation/aftercare/
/lada/                             → uk: /lada/  ru: /ru/lada/  x-default: /lada/
```

В карте сайта языки объявлены полными тегами `uk-UA`, `ru-UA`, `en`, в разметке страницы — только кодом языка.

## Заголовки и описания

Заголовок главной — из словаря интерфейса, заголовок страницы услуги — категории или подстраницы — и страницы базы знаний (хаб, статья, эксперт) — из frontmatter её файла. Форма — `<текст с запросом> — Lada N`, не длиннее 70 знаков; бренд в конце на всех страницах сайта, и у новых страниц тоже. У хаба и эксперта запроса ядра нет, поэтому вместо него текст по формулам §Целевые запросы. Ни один заголовок не собирается шаблоном с подставленным названием категории: одинаково устроенные заголовки страниц услуг — тот же дубль, только автоматический. Уникальность проверяется по всему набору, а не схемой: схема видит один файл, а нарушение возникает между файлами.

- Главная и `massage` разведены: общий запрос у главной, «масаж» — у страницы массажа, чтобы две страницы не конкурировали за одну формулировку.

- У бровей третья формулировка кластера — «татуаж брів» / «татуаж бровей» — стоит в тексте подстраницы, а не в заголовках: таблица выше держит две.
