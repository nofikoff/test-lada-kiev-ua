# Заголовочная часть страницы

Что обязана содержать каждая из девятнадцати страниц. Реализация — `src/components/SeoHead.astro`, у страниц ошибки — `src/components/ErrorHead.astro`. Проверка — `tests/seo-contract.spec.ts` по собранному HTML: требование относится к опубликованному файлу. Машиночитаемое описание — [structured-data.md](structured-data.md). Принято в пакете 001, 2026-09-06.

## Состав

| Элемент | Правило |
|---|---|
| `<html lang>` | `uk`, `ru` или `en`. Код `ua` — код страны и не употребляется нигде, где ожидается язык |
| `<title>` | на языке страницы; пара «заголовок + описание» уникальна по всему сайту |
| `description` | на языке страницы, 120–160 знаков |
| `canonical` | абсолютный, с `www`, в форме со слешем ([routes.md](routes.md)) |
| `hreflang` | три ссылки, включая себя, плюс `x-default` на украинскую версию; у подстраницы — две, uk и ru (§Языковые альтернативы) |
| Open Graph | тип, адрес, заголовок, описание, изображение с размерами, локаль, альтернативные локали, имя сайта |
| Twitter | тип карточки, заголовок, описание, изображение |
| Аналитика | счётчик `G-WZT8TJLSDP` в прежнем виде — [ADR-011](../adr/adr-011-analytics-snippet-unchanged-not-deferred.md) |

Изображение превью с 2026-09-27 собирается из портрета и меняет адрес вместе с ним — [home-hero.md](home-hero.md) §Превью ссылок и JSON-LD.

## Языковые альтернативы

Страница категории ссылается на ту же категорию в других языках, а не на главную. Соответствие вычисляется подстановкой префикса — [ADR-008](../adr/adr-008-urls-directory-format-latin-category-slugs.md).

```
/massage/   → uk: /massage/  ru: /ru/massage/  en: /en/massage/  x-default: /massage/
/ru/beauty/ → uk: /beauty/   ru: /ru/beauty/   en: /en/beauty/   x-default: /beauty/
```

Подстраница услуги ([ADR-028](../adr/adr-028-commercial-service-subpages.md)) называет только свои языки из реестра `serviceSubpages` (`src/i18n/paths.ts`): английской версии нет, а английская категория ей не эквивалент. Так же устроен `og:locale:alternate` — только второй язык подстраницы.

```
/depilation/sugaring/ → uk: /depilation/sugaring/  ru: /ru/depilation/sugaring/  x-default: /depilation/sugaring/
```

В карте сайта языки объявлены полными тегами `uk-UA`, `ru-UA`, `en`, в разметке страницы — только кодом языка.

## Заголовки и описания

Заголовок главной — из словаря интерфейса, заголовок страницы услуги — категории или подстраницы — из frontmatter её файла. Форма — `<текст с запросом> — Lada N`, не длиннее 70 знаков; бренд в конце на всех девятнадцати страницах. Ни один заголовок не собирается шаблоном с подставленным названием категории: шестнадцать одинаково устроенных заголовков страниц услуг — тот же дубль, только автоматический. Уникальность проверяется по всему набору, а не схемой: схема видит один файл, а нарушение возникает между файлами.

## Целевые запросы

У каждой из девятнадцати страниц одна основная формулировка запроса; эталон с падежными формами — `QUERIES` в `tests/support/site.ts`, проверка — `tests/voice.spec.ts`. Запросы выбраны 2026-09-27 по очевидным формулировкам, без статистики: данных Search Console нет. Появятся — карту перепроверить первой. Принято в пакете 004. Запросы подстраниц выбраны 2026-10-11 по Keyword Planner — [ADR-028](../adr/adr-028-commercial-service-subpages.md).

| Страница | uk | ru | en |
|---|---|---|---|
| главная | студія масажу та краси в центрі Києва | студия массажа и красоты в центре Киева | massage and beauty studio in central Kyiv |
| massage | масаж у Києві | массаж в Киеве | massage in Kyiv |
| depilation | депіляція у Києві; воскова депіляція | депиляция в Киеве; депиляция воском | waxing and sugaring in Kyiv |
| depilation/sugaring | шугаринг у Києві | шугаринг в Киеве | — |
| permanent | перманентний макіяж у Києві | перманентный макияж в Киеве | permanent makeup in Kyiv; powder brows |
| permanent/brows | перманентний макіяж брів у Києві; пудрові брови | перманентный макияж бровей в Киеве; пудровые брови | — |
| beauty | ламінування брів і вій, макіяж у Києві | ламинирование бровей и ресниц, макияж в Киеве | brow and lash lamination, makeup in Kyiv |

- Главная и `massage` разведены: общий запрос у главной, «масаж» — у страницы массажа, чтобы две страницы не конкурировали за одну формулировку.
- Все фрагменты запроса стоят в `<title>`, `<h1>`, описании и, у страниц услуг, в первом абзаце текста; основная формулировка начинается в первой половине описания.
- Запрос подстраницы не стоит в `<title>`, `<h1>` и описании её категории того же языка, а текст категории ведёт на подстраницу одной ссылкой не ниже второго раздела — [ADR-028](../adr/adr-028-commercial-service-subpages.md). У бровей запрещена формулировка, а не слово: «брів» / «бровей» рядом с «перманент», «татуаж», «пудров»; «ламінування брів» — запрос `beauty`. Английских подстраниц нет, поэтому `en` категорий свои запросы сохраняет.
- `<h1>` главной — бренд и строка «Студія масажу та краси в центрі Києва» в одном заголовке ([home-hero.md](home-hero.md) §Разметка).
- Коммерческий запрос обслуживает страница категории — [ADR-021](../adr/adr-021-no-query-landing-pages.md). Исключение — кластер, чью выдачу заняли специализированные страницы: он получает подстраницу категории, а категория отдаёт ей запрос — [ADR-028](../adr/adr-028-commercial-service-subpages.md). Информационные запросы получают страницы базы знаний — [ADR-023](../adr/adr-023-knowledge-base-pages-for-informational-queries.md).
