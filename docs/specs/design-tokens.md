# Дизайн-токены: палитра, шкала, ритм

Значения объявлены один раз — `:root` в `src/index.css`; `tailwind.config.js` на них ссылается. Проверки — `tests/contrast.spec.ts`, `tests/typography.spec.ts`. Гарнитура заголовков — [ADR-014](../adr/adr-014-heading-typeface-cormorant.md), подключение Tailwind — [ADR-010](../adr/adr-010-tailwind-3-via-postcss-no-integration.md). Принято в пакете 002, 2026-09-06.

## Правила

1. **Единственный источник.** Ни один компонент не объявляет цвет, кегль или вертикальный отступ литералом: `grep` по `src/` не находит hex вне `index.css`, `text-white/…` и `bg-lada-…`. Исключение одно — значок вкладки в `BaseLayout.astro`: `data:`-URI не видит CSS-переменных, и латунь `%23C9A961` записана в нём копией.
2. **Цвет хранится каналами** (`--ink: 18 16 14`), а не hex: только так Tailwind подставляет альфу в `rgb(var(--ink) / <alpha-value>)`. С готовым hex утилита `border-brass/20` генерируется, а цвет молча не меняется.
3. **Три уровня текста** — `--silk`, `--silk-dim`, `--muted`; произвольные прозрачности текста запрещены.
4. **`--muted` — только служебный текст** до 14 px (копирайт, сноска, подпись) и только на `--ink` или `--surface`. На `--raised` пара даёт 4.38:1 при пороге 4.5 — там служебный текст берёт `--silk-dim`.
5. **Акцент один** — латунь. Красного в проекте нет; розовое и янтарное пятна прототипа не перенесены: этих цветов нет в палитре.
6. **Ритм задаётся ролью секции** — `<Section rhythm="air">`, а не утилитами отступов в разметке.
7. **Надзаголовок не существует без заголовка** — `SectionHeading` принимает обе строки.

## Проверенные пары

Отношения по формуле WCAG, посчитаны 2026-09-06 по значениям палитры. На собранной странице пары не перебираются: `contrast.spec.ts` читает вычисленный цвет текста и его фактической подложки — ошибка обычно не в цвете, а в подложке.

| Пара | Отношение |
|---|---|
| `--silk` на `--ink` / `--surface` | 15.07 / 14.17 |
| `--silk-dim` на `--ink` / `--raised` | 8.68 / 7.47 |
| `--brass` на `--ink` / `--raised` | 8.44 / 7.26 |
| `--ink` на `--brass` (главная кнопка) | 8.44 |
| `--muted` на `--ink` / `--surface` | 5.09 / 4.78 |
| `--muted` на `--raised` | **4.38 — запрещена** |

## Мера колонки

Протяжённый текст (страницы категорий, «Про нас») держит самую длинную строку не выше 68 знаков на любой ширине. `--measure` задан на письменность, а не одним значением: средняя ширина знака у кириллицы около 8.7 px, у латиницы 7.3 px, и одна колонка даёт английскому тексту примерно на четыре знака больше. Значения и замеры — комментарий у `--measure` в `index.css`. Меряется самая длинная строка, а не среднее по абзацу: последняя строка заполнена частично и тянет среднее вниз, так колонка в 72 знака выглядит как 64.

## Совместимость

Проверки опираются на идентификаторы `#tab-*`, `#panel-*`, `#mobile-menu`, роли `tablist`/`tab`/`tabpanel` со связями `aria-controls`/`aria-labelledby` и атрибуты `data-service-copy`, `data-price-tabs`. Смена оформления их не трогает.
