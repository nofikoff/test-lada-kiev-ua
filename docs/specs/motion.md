# Движение

Keyframes — `src/styles/ambience.css`, носители — `src/index.css` и компоненты. Проверки — `tests/reduced-motion.spec.ts`, `tests/contrast.spec.ts`. Почему только CSS и таймлайны прокрутки — [ADR-015](../adr/adr-015-motion-css-scroll-driven-no-script.md), почему фон один фиксированный слой — [ADR-016](../adr/adr-016-ambient-background-gradients-fixed-layer.md). Принято в пакете 002, 2026-09-06.

## Правила

1. **Только `transform` и `opacity`.** Исключение одно — тление надзаголовков (`ember`) на `text-shadow`: раскладку не двигает, стоит на строках в 3–5 слов. Пульсация главной кнопки поэтому сделана волной света по лицу кнопки, а не кольцом `box-shadow`.
2. **Ноль исполняемого кода.** Ни одна анимация не требует скрипта; бюджет — `scripts/analyze-bundle.mjs`.
3. **Невидимость живёт внутри `@supports`.** Обратный порядок — `opacity: 0` в базовом правиле, анимация его снимает — оставляет блок невидимым навсегда там, где таймлайн не поддержан. Это единственная ошибка здесь, которая выглядит как пустая страница, и ни один движок прогона её не воспроизводит; ловит разбор собранного CSS в `reduced-motion.spec.ts`.

   ```css
   @media (prefers-reduced-motion: no-preference) {
     @supports (animation-timeline: view()) {
       .reveal { animation: reveal linear both; animation-timeline: view(); }
     }
   }
   ```

4. **Уменьшенное движение выключает всё**, включая плавную прокрутку: `scroll-behavior: smooth` не анимация и не переход, `animation: none` его не гасит. Отмена стоит рядом с объявлением в `index.css`. Конечные состояния видимы — это даёт правило 3.
5. **Не больше трёх изменений яркости в секунду.** Замер 2026-09-07 по длительностям в коде: быстрейший носитель яркости — кольцо главной кнопки, 4.5 с на цикл, 0.44/с. Зерно идёт чаще (8 шагов за 6 с), но двигает `transform`, а не яркость; число шагов зафиксировано потому, что при нескольких десятках подрагивание становится мерцанием.
6. **Под текстом первого экрана ничего не дышит** — затемнение работает только над портретом ([home-hero.md](home-hero.md) §Движение), поэтому контраст текста не зависит от фазы анимации.

## Сборка

`vite.build.cssMinify: 'esbuild'` в `astro.config.mjs` не менять на lightningcss: тот сворачивает `animation` рядом с `animation-timeline` в сокращённую запись, которую браузеры не принимают, и правило отбрасывается целиком. Глазами это не видно — видимое состояние и есть исходное; ловит проверка сокращённой записи в `tests/reduced-motion.spec.ts`.

## Поддержка

`animation-timeline: view()` / `scroll()`: Chrome 115+, Safari 26+, Firefox 158+ — 87.22% посетителей (caniuse, 2026-09-06). Остальные видят страницу без проявлений и с постоянно плотной шапкой. `initial-letter` (буквица на страницах категорий): Chrome и Safari, Firefox нет — 91.66%; без поддержки абзац начинается обычной буквой, имитация через `float` не делается — разъезжается при переносе.

## Не проверяется автоматически

Уместность темпа (эталон — `prototype.html`, согласованный в пакете 002; в истории на коммите ade2e87) и общая целостность страницы в Firefox.
