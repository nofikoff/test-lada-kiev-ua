## From answer to page text

Формулировка на странице — наша, факт — Лады: ни срока, ни числа, ни причины сверх сказанного.

- **Противопоказания — нейтральной лексикой** ([voice.md](voice.md) §Contract, «Лечение не обещается»): «зараза всякая» → инфекционные заболевания кожи; «спид и прочие болячки» → ВИЧ и другие инфекционные заболевания; «проблемы с кровью» → нарушения свёртываемости крови; «неадекватам», «алко состояние» → «в состоянии опьянения». «И тд» не переносится: перечень заканчивается названным, дальше — «уточните у мастера при записи».
- **«До 18 лет без родителей»** — несовершеннолетним только с родителем; запрета по возрасту нет.
- **Препараты, разжижающие кровь, страница отменять не советует**, а просит сказать о них при записи: отменять их можно только с врачом. Совет бросить назначенный препарат — медицинская рекомендация, права на которую у студии нет.
- **Срок держания бровей** — 2–3 года при поверхностной работе, глубже — дольше; на жирной коже работают глубже, потому что пигмент уходит быстрее. «Сколько вы хотите» → глубину выбирают вместе с мастером. Мастер по имени не называется (ADR-019).
- **Паста против воска** — «по росту волоса рвётся» → паста снимает волос по направлению роста, поэтому вросших волос меньше. «Мне например» — личный опыт Лады; у страниц без её подписи — «некоторым клиентам паста менее болезненна, чем воск».
- **Epilax называется**: это факт о материале.
- **Межресничка 60 мин и губы 3 часа** — для `/permanent/`, не для страницы бровей.
- **Сроков ограничений до и после процедуры Лада не назвала**: на страницах стоит общая рекомендация из внешних источников — [content-model.md](content-model.md) §Service subpage.
