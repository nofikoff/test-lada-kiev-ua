# Data Model

**Фича**: [spec.md](./spec.md) | **Решения**: [research.md](./research.md)

Три источника контента, ни один не пересекается с другим: прайс — структурированные данные, тексты страниц категорий — Markdown, подписи интерфейса — типизированный модуль. Разметка не хранит контента.

## Локали

```ts
type Locale = 'uk' | 'ru' | 'en';   // uk — основная, отдаётся без префикса
```

Соответствие адресов и тегов языка:

| Локаль | Префикс адреса | Тег языка документа | Тег в карте сайта |
|--------|----------------|---------------------|-------------------|
| `uk`   | нет            | `uk`                | `uk-UA`           |
| `ru`   | `/ru`          | `ru`                | `ru-UA`           |
| `en`   | `/en`          | `en`                | `en`              |

Код `ua` не употребляется нигде. Действующий код использует его как код языка — при переносе он заменяется, адреса не меняются.

## Категория услуг

Четыре значения, каждое — одна страница на язык. Не хранится файлом: это перечисление, от которого зависят маршруты.

```ts
type ServiceCategory = 'massage' | 'depilation' | 'permanent' | 'beauty';
```

Адрес страницы совпадает со значением и одинаков во всех языках: `/massage`, `/ru/massage`, `/en/massage`.

## Группа прайса

Единица отображения внутри перечня; у каждой группы свой заголовок из словаря интерфейса. Группа принадлежит ровно одной категории — это связь, задающая, какие позиции попадут на какую страницу.

| Группа | Категория | Форма цены | Соответствие в действующем коде |
|--------|-----------|------------|--------------------------------|
| `fullBodyMassage` | `massage` | варианты длительности | `bodyMassageData` |
| `localMassage` | `massage` | варианты длительности | `localMassageData` |
| `exotic` | `massage` | варианты длительности | `exoticData` |
| `womenDepilation` | `depilation` | одна цена | `depilationZones` |
| `combos` | `depilation` | одна цена | `depilationCombos` |
| `menDepilation` | `depilation` | одна цена | `maleDepilationZones` |
| `permanentBrows` | `permanent` | одна цена | `beautyData.permanentBrows` |
| `permanentLips` | `permanent` | одна цена | `beautyData.permanentLips` |
| `permanentEyeliner` | `permanent` | одна цена | `beautyData.permanentEyeliner` |
| `browsLashes` | `beauty` | одна цена | `beautyData.browsLashes` |
| `makeupHair` | `beauty` | одна цена | `beautyData.makeup` |

## Позиция прайса

Файл `src/data/prices.json` — массив объектов, у каждого явный `id` (требование загрузчика `file()`: без идентификатора запись не принимается).

```ts
{
  id: string;                    // уникален в пределах всего файла
  group: PriceGroup;             // определяет и блок отображения, и категорию через таблицу выше
  name:        Record<Locale, string>;
  description?: Record<Locale, string>;
  price: PriceValue;
}

type PriceValue =
  | { kind: 'fixed';    amount: number }                                  // одна цена, грн
  | { kind: 'variants'; unit: PriceUnit;
                        variants: { count: number; amount: number }[] }   // цена за единицу объёма
  | { kind: 'share';    percent: number; note: Record<Locale, string> };  // доля от базовой процедуры

type PriceUnit = 'minutes' | 'sessions';
```

**Поправка, внесённая при выполнении Step 2.2**: вариант несёт `count` и единицу `unit`, а не `minutes`. Первоначальная запись описывала только длительность, а одна позиция действующего прайса — антицеллюлитный массаж в группе `exotic` — назначена по числу сеансов: 950 за сеанс, 4500 за пять, 8500 за десять (`PriceList.tsx:134-142`, подписи `session`, `sessions5`, `sessions10` словаря). Ни одна из трёх форм цены её не выражала.

Записать её длительностями значило бы поставить `minutes: 5` против 4500 грн и отрисовать «5 хв» — ровно тот тихий сбой, ради которого этот шаг выделен отдельно. Формы цены по-прежнему три; изменилась только внутренность варианта, и все правила остаются: число живёт в данных, слово — в словаре локали (`sessionOne`, `sessionsTemplate`, `durationTemplate` в `src/i18n/ui.ts`).

**Правила валидации** (проверяются схемой при сборке; нарушение останавливает сборку):

- Все три локали присутствуют в `name`; если `description` задано — тоже все три. Отсутствие языка — ошибка, а не пустая строка.
- `amount` — целое положительное. `count` — целое положительное.
- `variants` непуст, значения `count` внутри позиции не повторяются.
- `percent` в диапазоне 1–99.
- `id` уникален по всему файлу.
- `group` — одно из одиннадцати значений таблицы.

**Подводный камень идентификаторов**: три позиции повторяются между группами с разными ценами — перекрытие старого перманентного макияжа стоит 2800 в группах бровей и губ и 2200 в группе межресничного пространства, коррекция присутствует во всех трёх группах. Идентификатор поэтому строится от группы, а не от названия: `permanent-brows-coverup`, `permanent-lips-coverup`, `permanent-eyeliner-coverup`. Идентификатор от названия схлопнул бы три разные позиции в одну и потерял две цены.

**Долевые цены**: коррекция в течение 28–60 дней стоит 50% от процедуры. Действующий код хранит для неё цену `0` и подменяет её строкой `50%` при отображении (`src/components/PriceList.tsx:381`). В новой модели это `kind: 'share'` — цена перестаёт быть ложной, а машиночитаемый перечень предложений такие позиции пропускает: предложение с нулевой ценой описывает бесплатную услугу.

**Независимость от языка**: сумма, длительность, группа и доля одинаковы для всех локалей. От языка зависят только название, описание и текстовая подпись доли.

## Конфигурация вкладок главной страницы

Не данные, а раскладка: перечисляет, какие группы показывает каждая вкладка. Живёт в модуле рядом со словарём интерфейса.

```ts
const tabs = [
  { id: 'bodyMassage', groups: ['fullBodyMassage', 'localMassage'] },
  { id: 'exotic',      groups: ['exotic'] },
  { id: 'depilation',  groups: ['womenDepilation', 'combos', 'menDepilation'] },
  { id: 'beauty',      groups: ['browsLashes', 'makeupHair',
                                'permanentBrows', 'permanentLips', 'permanentEyeliner'] },
];
```

Состав повторяет действующие вкладки, включая то, что перманентный макияж показывается внутри вкладки бьюти-услуг, хотя ему соответствует отдельная страница категории. Обе группировки читают один и тот же массив позиций, поэтому разойтись не могут: вкладки не хранят ни одной цены.

## Страница категории

Коллекция `services`, загрузка через `glob()` из `src/content/services/<locale>/<category>.md`. Двенадцать файлов: четыре категории × три локали.

```ts
// frontmatter
{
  category: ServiceCategory;   // должна совпадать с именем файла
  title: string;               // заголовок страницы и элемент title
  description: string;         // описание страницы, 120–160 символов
  heading: string;             // заголовок h1, может отличаться от title
}
// тело файла — текст страницы, не менее 400 слов
```

**Правила валидации**: `category` совпадает с именем файла; для каждой из четырёх категорий существуют ровно три файла — по одному на локаль. Недостающий файл останавливает сборку: страница без текста хуже отсутствующей страницы.

Цены на страницу не переносятся копированием — они берутся из позиций, чьи группы принадлежат этой категории.

## Словарь интерфейса

`src/i18n/ui.ts`, объект `as const`. Тип выводится из основной локали, поэтому недостающий ключ в русской или английской версии — ошибка типов, а не пустое место на странице.

Содержит: пункты навигации, подписи кнопок, заголовки секций и групп прайса, единицу валюты, шаблон подписи длительности, примечание к разделу перманентного макияжа, тексты страницы ошибки.

Подпись длительности собирается из числа и шаблона локали, а не хранится строкой. Сегодня строка `«60 хв»` хранится отдельно от числа 60, и рассинхрон между ними ничем не запрещён.

## Метаданные страницы

Не хранятся; вычисляются при генерации из локали, адреса и источника контента.

```ts
{
  title: string;           // из frontmatter либо из словаря для главной
  description: string;
  canonical: URL;          // абсолютный, форма со слешем на конце
  alternates: Record<Locale, URL>;   // все три локали
  xDefault: URL;                     // всегда украинская версия
  ogImage: URL;                      // общее изображение, постоянный адрес
}
```

Требование FR-009 — уникальность пары «заголовок + описание» по всем страницам — проверяется сквозным тестом по собранному сайту, а не схемой: схема видит один файл, а нарушение возникает между файлами.

## Эталонная фикстура контента

`tests/fixtures/legacy-content.json` — снимок всех строк действующего словаря переводов, разложенный по локалям. Снимается до удаления старого источника, коммитится, остаётся в проекте постоянно.

```ts
Record<Locale, string[]>
```

Единственный источник, по которому проверяется, что при переносе не потерялся текст. Формируется из `src/i18n/translations.ts` рекурсивным обходом с извлечением строковых значений — переносить руками нельзя, ручной перенос воспроизводит ровно ту ошибку, которую фикстура должна ловить.
