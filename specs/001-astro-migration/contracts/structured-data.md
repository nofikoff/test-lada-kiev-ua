## Страница категории

Два объекта: описание услуги с перечнем предложений и цепочка навигации.

**Услуга**:

| Поле | Значение |
|------|----------|
| Название | заголовок страницы категории |
| Описание | описание из frontmatter |
| Исполнитель | ссылка на организацию главной страницы |
| Область обслуживания | Киев |
| Перечень предложений | позиции категории |

**Предложение** — одно на позицию прайса:

- позиция с фиксированной ценой → одно предложение с этой суммой;
- позиция с вариантами длительности → предложение на каждый вариант, длительность указывается как свойство предложения;
- позиция с долевой ценой → **не публикуется**.

Валюта — гривна. Наличие — в наличии.

Исключение долевых позиций обязательно: предложение без цены или с нулевой ценой описывает бесплатную услугу. Отсутствие позиции честнее ложного утверждения — и в выдаче поисковика, и перед посетителем, который увидит цену «0».

**Цепочка навигации**: главная страница → страница категории. Названия — на языке страницы.

## Что не размечается

- Отзывов и оценок нет — размечать их нечем, а выдуманная разметка отзывов является нарушением правил поисковых систем.
- Возможность записи не размечается: онлайн-записи на сайте нет, запись идёт по телефону. Разметка действия, которого нет, приведёт посетителя в тупик.

## Проверка

1. Разметка на каждой из пятнадцати страниц разбирается как корректная структура данных.
2. Валидатор структурированных данных не выдаёт ошибок ни на одной странице.
3. Ценовой диапазон главной страницы совпадает с фактическим минимумом и максимумом прайса.
4. Число предложений на странице категории совпадает с числом отображаемых позиций за вычетом долевых.
5. Ни одно предложение не имеет нулевой цены.
6. Текстовые поля соответствуют языку страницы.
