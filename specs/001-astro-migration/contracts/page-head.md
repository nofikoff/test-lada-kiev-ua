# Контракт: заголовочная часть страницы

Что обязана содержать каждая страница сайта. Проверяется сквозным тестом по собранному HTML, а не по исходникам компонентов: требование относится к опубликованному файлу.

## Обязательный состав

| Элемент | Правило |
|---------|---------|
| Язык документа | Тег локали страницы: `uk`, `ru` или `en`. Значение `ua` запрещено |
| Заголовок | Непустой, на языке страницы. Пара «заголовок + описание» уникальна по всему сайту |
| Описание | Непустое, на языке страницы, 120–160 символов |
| Канонический адрес | Абсолютный, со схемой и доменом, в форме со слешем на конце |
| Языковые альтернативы | Три ссылки — по одной на локаль — плюс ссылка версии по умолчанию, ведущая на украинскую |
| Предпросмотр в соцсетях | Тип, адрес, заголовок, описание, изображение, локаль, альтернативные локали, имя сайта |
| Предпросмотр в микроблогах | Тип карточки, заголовок, описание, изображение |
| Машиночитаемое описание | См. [structured-data.md](./structured-data.md) |
| Аналитика | Счётчик с тем же идентификатором и тем же способом загрузки, что до миграции |

## Правила языковых альтернатив

Каждая страница перечисляет **все** свои языковые версии, включая себя. Страница категории ссылается на ту же категорию в других локалях, а не на главную.

```
/massage/     → uk: /massage/     ru: /ru/massage/     en: /en/massage/     по умолчанию: /massage/
/ru/beauty/   → uk: /beauty/      ru: /ru/beauty/      en: /en/beauty/      по умолчанию: /beauty/
```

Адрес категории одинаков во всех локалях, поэтому соответствие вычисляется подстановкой префикса и не требует таблицы. Это причина, по которой адреса не локализуются.

Версия по умолчанию — всегда украинская: она отдаётся на корне и обслуживает посетителя, чей язык не совпал ни с одним из трёх.

## Заголовки и описания

Заголовок главной страницы берётся из словаря интерфейса, заголовок страницы категории — из frontmatter её файла. Ни один заголовок не собирается конкатенацией шаблона с названием категории: одинаково устроенные заголовки на двенадцати страницах — тот же дубль, только автоматический.

Требование уникальности проверяется по всему набору: собираются пары «заголовок + описание» всех пятнадцати страниц, любое совпадение — провал теста. Сегодня совпадают все пятнадцать, поскольку метаданные заданы один раз в общем шаблоне.

## Изображение предпросмотра

Одно на весь сайт, лежит по постоянному адресу в статических файлах, не тяжелее 300 КБ. Оптимизации сборки к нему не применяются намеренно: имена оптимизированных файлов содержат хэш и меняются при пересборке, а соцсети кэшируют адрес.

Размеры изображения объявляются явно — без них часть площадок не строит крупную карточку.

## Проверка

Для каждой из пятнадцати страниц:

1. Тег языка совпадает с локалью адреса.
2. Ровно один заголовок первого уровня в теле страницы.
3. Канонический адрес абсолютен и совпадает с фактическим адресом страницы.
4. Ровно четыре ссылки языковых альтернатив, из них одна — версия по умолчанию.
5. Каждая альтернатива ведёт на существующую страницу, отвечающую кодом 200.
6. Пара «заголовок + описание» не повторяется ни на одной другой странице.
7. Метаданные предпросмотра присутствуют полностью, объявленная локаль совпадает с языком страницы.
8. Счётчик аналитики присутствует с прежним идентификатором.
