# Контракт: адреса и поведение веб-сервера

Публичный контракт сайта. Нарушение любой строки таблицы — регрессия, даже если страница выглядит правильно.

## Канонический хост

`https://www.lada.kiev.ua` — единственный хост, который сайт объявляет о себе. Хост без `www` отвечает постоянным перенаправлением на него (проверено на действующем сайте 2026-09-06).

Все абсолютные адреса — канонические, языковые альтернативы, метаданные предпросмотра, карта сайта — используют форму с `www`. Действующая разметка объявляет адреса без `www` (`index.html:13`, `index.html:16`), то есть указывает на перенаправление; при переносе это устраняется.

## Форма адреса со слешем

Сборка выдаёт `<путь>/index.html`. Запрос без завершающего слеша (`/ru`) веб-сервер перенаправляет на форму со слешем постоянным перенаправлением — стандартное поведение Apache при включённом `DirectorySlash`.

Следствия, обязательные к соблюдению:

- Канонический адрес страницы объявляется **в форме со слешем**. Канонический адрес без слеша противоречил бы фактическому адресу после перенаправления.
- Внутренние ссылки ставятся сразу на форму со слешем — иначе каждый переход внутри сайта стоит лишнего обращения к серверу.
- Действующие адреса `/ru` и `/en`, стоящие во внешних источниках, продолжают работать через это перенаправление. Терять их нельзя.

## Правила `.htaccess`

**Удаляется** правило подстановки главной страницы (`public/.htaccess:6-10`). Оно отдавало главную страницу с кодом 200 на любой несуществующий адрес — механика одностраничного приложения. На статическом сайте это превращает любую опечатку в адресе в страницу-дубль, отвечающую успехом.

**Добавляется**:

| Правило | Требование |
|---------|------------|
| Страница ошибки | `ErrorDocument 404` на украинскую страницу ошибки; отдельные объявления внутри `/ru/` и `/en/`, чтобы язык страницы ошибки соответствовал разделу |
| Кэш файлов сборки | `_astro/*` — год, `immutable`; имена содержат хэш содержимого, поэтому обновление приходит через новое имя |
| Кэш изображений и шрифтов | долгий срок для файлов с хэшем в имени; изображение предпросмотра в `public/` — умеренный, его имя постоянно |
| Кэш HTML | минуты, с обязательной перепроверкой; иначе правка текста не доходит до посетителя |
| Сжатие | текстовые типы, включая `svg`, `json`, `xml` |

## Выкладка

Перед сетью доставки контента, поэтому порядок действий важен:

| Шаг | Требование |
|-----|------------|
| 1 | Файлы предыдущей сборки удаляются с сервера. Оставленные, они отвечают кодом 200 и остаются в индексе как дубли |
| 2 | Выкладывается новая сборка целиком |
| 3 | Сбрасывается кэш сети доставки для постоянных адресов: HTML-страниц, изображения предпросмотра, файла правил для роботов, карты сайта |

Файлы в `_astro/` содержат хэш содержимого в имени, сброса не требуют и кэшируются надолго. Сброса требует ровно то, у чего адрес постоянный: измерение действующего сайта показало кэширование статики на четыре часа, то есть без сброса замена изображения предпросмотра дойдёт до соцсетей не сразу.

HTML на стороне сети доставки не кэшируется — выкладка страниц видна немедленно. Это снимает риск, что посетитель получит старую страницу, ссылающуюся на уже удалённые файлы сборки, но снимает только на стороне сети: кэш браузера у вернувшегося посетителя остаётся, поэтому срок кэширования HTML задаётся минутами.

После выкладки проверяется, что файл правил для роботов отдаётся тот, что лежит в репозитории: сегодня его отдаёт сама сеть доставки, поскольку в проекте файла нет.

## Проверки контракта

Выполняются против собранного сайта, поднятого локально:

1. Каждый адрес таблицы отвечает указанным кодом.
2. Запрос `/ru` (без слеша) приводит к странице `/ru/`.
3. Запрос заведомо несуществующего адреса отвечает кодом 404 — не 200.
4. Запрос несуществующего адреса внутри `/en/` отдаёт страницу ошибки на английском.
5. Ни один файл сборки не остаётся недостижимым: перечень адресов карты сайта совпадает с перечнем сгенерированных страниц, кроме страниц ошибки.
6. Все абсолютные адреса в разметке используют хост с `www`; ни один не ведёт на перенаправление.

После выкладки, против рабочего сайта:

7. `/sitemap.xml` отдаёт XML, а не HTML. Сегодня он отдаёт HTML главной страницы с кодом 200.
8. Заведомо несуществующий адрес отвечает кодом 404.
9. Файлы предыдущей сборки более не отвечают кодом 200.
