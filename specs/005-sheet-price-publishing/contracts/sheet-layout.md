# Contract: Sheet layout

Таблица «lada.kiev.ua — цены», владелец ruslan.novikov@gmail.com. Идентификатор таблицы — переменная environment `PRICES_SHEET_ID`, у пробного прогона — `PRICES_SHEET_ID_DRY_RUN`. Лист один, имя `Цены`. Этот контракт — общий для `rebuild-sheet.mjs`, `publish.mjs`, `report.mjs` и `apps-script/Code.js`; поменять адрес ячейки в одном месте и не поменять в остальных — значит сломать публикацию.

| Адрес | Содержимое | Правит Лада |
|---|---|---|
| `B1` | галочка (проверка данных «флажок») | **да** |
| `B2` | `↑ Опубликовать` — подпись под галочкой: столбец `A` скрыт, подпись в нём Лада не видит | нет |
| `C1` | статус (data-model.md §Status transitions) | нет |
| `A3:F3` | `ключ`, `Услуга`, `Вариант`, `Сумма, грн`, `На сайте`, `Пометка` | нет |
| `A4:F<n>` | строки SheetRow | только `D4:D<n>` |

- Столбцы `A` и `E` скрыты, строки 1–3 закреплены.
- Ширина `B` 220 px, `C` 80, `D` 100, `F` 240; `B` и `F` переносят текст. Названия доходят до 54 символов, растянутый `B` уводит суммы за край экрана телефона.
- Защита: лист целиком, редакторы — только `PRICES_SHEET_OWNER` и `GCP_SERVICE_ACCOUNT`; исключения `B1` и `D4:D<n>`.
- Проверка ввода `D4:D<n>`: целое число от 1 до 100000, отклонять ввод, подсказка «Только целое число гривен от 1 до 100 000».
- Условное форматирование `D4:D<n>`: `=AND($D4<>"",$D4<>$E4)` → жёлтая заливка; `=$F4<>""` → красная заливка; красное правило выше жёлтого.
- `publish.mjs` читает `A4:E` одним `values.get` с `valueRenderOption=UNFORMATTED_VALUE`.
- `report.mjs` пишет `C1`, `E4:E<n>`, `F4:F<n>` одним `values.batchUpdate`.
- `rebuild-sheet.mjs` пишет всё, кроме `D` у ключей, которые сохранились и у которых `published` совпадает с `prices.json`: там сумма Лады сохраняется. У ключей с расхождением, то есть с правкой в git, `D` и `E` получают сумму из `prices.json`.
