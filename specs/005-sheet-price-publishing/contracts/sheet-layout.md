# Contract: Sheet layout

Таблица «lada.kiev.ua — цены», владелец ruslan.novikov@gmail.com. Идентификатор таблицы — переменная environment `PRICES_SHEET_ID`, у пробного прогона — `PRICES_SHEET_ID_DRY_RUN`. Лист один, имя `Цены`. Этот контракт — общий для `rebuild-sheet.mjs`, `publish.mjs`, `report.mjs` и `apps-script/Code.js`; поменять адрес ячейки в одном месте и не поменять в остальных — значит сломать публикацию.

| Адрес | Содержимое | Правит Лада |
|---|---|---|
| `B1` | галочка (проверка данных «флажок») | **да** |
| `B2` | `↑ Опубликовать` — подпись под галочкой: столбец `A` скрыт, подпись в нём Лада не видит | нет |
| `C1` | статус (data-model.md §Status transitions) | нет |
| `A3:F3` | `ключ`, `Услуга`, `Вариант`, `Сумма, грн`, `На сайте`, `Пометка` | нет |
| `A4:F<n>` | строки SheetRow, перед строками каждой группы — строка GroupHeader (`A` пусто, подпись группы в `B`) | только `D` строк SheetRow |

- Столбцы `A` и `E` скрыты, строки 1–3 закреплены.
- Ширина `B` 220 px, `C` 80, `D` 100, `F` 240; `B`, `C` и `F` переносят текст. Названия доходят до 54 символов, растянутый `B` уводит суммы за край экрана телефона; подпись строки цены пастой `сахар, 60 мин` не помещается в 80 px `C` (пакет 006, data-model §Sheet row of a sugar amount).
- GroupHeader: `A:F` жирным шрифтом с серой заливкой; подпись — `ui.ru.priceList.sections[group]` из `src/i18n/ui.ts` (research.md §R12). Строка без ключа в `A` для всех четырёх файлов означает «не позиция».
- Защита: лист целиком, редакторы — только `PRICES_SHEET_OWNER` и `GCP_SERVICE_ACCOUNT`; исключения `B1` и по одному диапазону `D` на группу, от первой до последней её SheetRow. `D` строки GroupHeader защищена.
- Проверка ввода `D4:D<n>`: целое число от 1 до 100000, отклонять ввод, подсказка «Только целое число гривен от 1 до 100 000».
- Условное форматирование `D4:D<n>`: `=AND($D4<>"",$D4<>$E4)` → жёлтая заливка; `=$F4<>""` → красная заливка; красное правило выше жёлтого.
- `publish.mjs` читает `A4:E` одним `values.get` с `valueRenderOption=UNFORMATTED_VALUE`, пропускает строки с пустым `A` и сохраняет в отчёте номер строки листа у каждой SheetRow.
- `report.mjs` пишет `C1` и блок `E4:F<n>` одним `values.batchUpdate`; строка блока берётся по номеру из отчёта, строки без SheetRow получают пустые `E` и `F`.
- `rebuild-sheet.mjs` пишет всё, кроме `D` у ключей, которые сохранились и у которых `published` совпадает с `prices.json`: там сумма Лады сохраняется. У ключей с расхождением, то есть с правкой в git, `D` и `E` получают сумму из `prices.json`. Группа, позиции которой в `prices.json` идут не подряд, и группа без подписи в `ui.ru.priceList.sections` останавливают перестройку до записи в лист.
