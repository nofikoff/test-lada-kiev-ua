# Retired packages

Журнал жизненного цикла пакетов `specs/NNN-*`: строка = событие, состояние номера = его последнее событие, отсутствие номера в списке — активная работа. Строки только дописываются: по ним восстанавливается содержимое (`git checkout <Sha> -- specs/NNN-*`) и проверяется, жив ли номер. Номер новой feature журнал не выдаёт.

События: `dissolved` — содержимое разложено по жанрам, ссылки переставлены; `retired` — каталог снят из дерева; `abandoned` — работа не будет сделана; `reopened` — каталог восстановлен. `Sha` у `retired` — состояние **до** удаления.
