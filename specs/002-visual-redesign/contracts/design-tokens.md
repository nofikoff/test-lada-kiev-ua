# Контракт: дизайн-токены

Что обязано быть верным после работы. Значения токенов — в [data-model.md](../data-model.md).

## Единственный источник

Палитра, типографическая шкала и ритм объявляются один раз, в `src/index.css`, слоем `@layer base` на `:root`. Ни один компонент не объявляет собственный цвет, кегль или вертикальный отступ литералом.

```css
:root {
  --ink: 18 16 14;        /* каналы, не hex — этого требует <alpha-value> */
  --brass: 201 169 97;
  --rhythm-air: clamp(6rem, 14vh, 11rem);
}
```

`tailwind.config.js` ссылается на переменные форматной строкой и не дублирует значения:

```js
colors: {
  ink: 'rgb(var(--ink) / <alpha-value>)',
  brass: 'rgb(var(--brass) / <alpha-value>)',
}
```

**Проверяемое следствие**: `grep` по `src/` не находит ни одного шестнадцатеричного цвета вне `index.css`, ни одного `text-white/`, ни одного `bg-lada-`.

## Имена

| Слой | Имя токена | Имя утилиты Tailwind |
|---|---|---|
| Цвет | `--ink`, `--surface`, `--raised`, `--brass`, `--brass-lt`, `--silk`, `--silk-dim`, `--muted` | `bg-ink`, `text-silk`, `border-brass/20` |
| Ритм | `--rhythm-air`, `--rhythm-work`, `--rhythm-tight` | применяются примитивом `Section`, не утилитой |
| Шкала | классы компонентного слоя `.eyebrow`, `.lede`, `.section-title`, `.display` | — |

Префикс `lada-` уходит целиком: он ничего не различал (весь проект — один сайт) и удлинял каждое имя. Имя `.section-title` при этом сохраняется, хотя ступень шкалы зовётся `title`: класс стоит в четырёх компонентах, которые пересобираются в разных шагах, и переименование оставило бы их заголовки без оформления до последнего из них.

## Правила применения

1. **Три уровня текста, не восемь.** Любой текст берёт один из `--silk`, `--silk-dim`, `--muted`. Произвольные прозрачности запрещены.
2. **`--muted` только для служебного текста** от 14 px и мельче, и только на `--ink` или `--surface`. Смысловой текст этим уровнем не набирается. На `--raised` пара даёт 4.38:1 и проваливает порог ([data-model.md](../data-model.md)) — там служебный текст берёт `--silk-dim`.
3. **Акцент один.** Латунь — единственный цветной акцент сайта. Красного в проекте не остаётся.
4. **Ритм задаётся ролью секции**, а не набором утилит в разметке. Компонент объявляет `<Section rhythm="air">`, а не `py-20 md:py-32`.
5. **Заголовок и надзаголовок — одна пара.** `SectionHeading` принимает обе строки; надзаголовок без заголовка не существует.

## Гарнитуры

`--font-cormorant` заменяет `--font-playfair` в `astro.config.mjs` и в `tailwind.config.js` (`fontFamily.serif`). Предзагрузка остаётся отбором по подмножеству языка страницы без указания начертания — причина в комментарии `BaseLayout.astro:28-39`.

Ни один шрифт не грузится со стороннего домена: файлы скачиваются на сборке, как сейчас.

## Совместимость

Работа не меняет: идентификаторы `#tab-*`, `#panel-*`, `#mobile-menu`; роли `tablist`/`tab`/`tabpanel` и связи `aria-controls`/`aria-labelledby`; атрибут `data-service-copy` (по нему считается объём текста категории); атрибут `data-price-tabs`.

Классы активной и неактивной вкладки объявлены дважды — в разметке `PriceTabs.astro` и в его же встроенном скрипте. При смене оформления вкладок правятся оба места; расхождение проявится только после первого переключения вкладки, то есть мимо статической проверки.
