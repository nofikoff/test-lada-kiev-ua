# Data Model: дизайн-токены

Модель этой работы — не данные предметной области (они не меняются), а набор токенов оформления. Здесь их состав и правила; имена и способ применения — в [contracts/design-tokens.md](./contracts/design-tokens.md).

## Палитра

Переменная хранит **каналы**, а не готовый цвет: этого требует формат Tailwind `rgb(var(--x) / <alpha-value>)` (research.md §R3).

| Токен | Каналы | Hex | Роль |
|---|---|---|---|
| `--ink` | `18 16 14` | `#12100E` | фон страницы и сквозного слоя |
| `--surface` | `26 23 20` | `#1A1714` | секция-контраст |
| `--raised` | `36 31 26` | `#241F1A` | приподнятая поверхность: карточка сертификатов, раскрытое меню |
| `--brass` | `201 169 97` | `#C9A961` | акцент: надзаголовки, цены, линии, главная кнопка |
| `--brass-lt` | `224 200 138` | `#E0C88A` | блик, наведение |
| `--silk` | `237 228 214` | `#EDE4D6` | основной текст, заголовки |
| `--silk-dim` | `184 174 160` | `#B8AEA0` | вторичный текст, описания |
| `--muted` | `140 131 119` | `#8C8377` | подписи, копирайт, сноски |

### Проверенные пары

Считано по формуле относительной яркости WCAG; проверка на собранной странице — `tests/contrast.spec.ts` (research.md §R11).

| Пара | Отношение | Уровень |
|---|---|---|
| `--silk` на `--ink` | 15.07:1 | AAA |
| `--silk` на `--surface` | 14.17:1 | AAA |
| `--silk-dim` на `--ink` | 8.68:1 | AAA |
| `--silk-dim` на `--raised` | 7.47:1 | AAA |
| `--brass` на `--ink` | 8.44:1 | AAA |
| `--brass` на `--raised` | 7.26:1 | AAA |
| `--brass-lt` на `--ink` | 11.57:1 | AAA |
| `--ink` на `--brass` (кнопка) | 8.44:1 | AAA |
| `--muted` на `--ink` | 5.09:1 | AA |
| `--muted` на `--surface` | 4.78:1 | AA |
| **`--muted` на `--raised`** | **4.38:1** | **не проходит** |

Последняя строка — не оплошность подбора, а граница применения. `--muted` светлеет медленнее, чем поверхность под ним, и на третьем уровне глубины отношение уходит под 4.5:1. SC-001 требует расчёта по всем сочетаниям, поэтому пара обязана быть либо посчитана и разрешена, либо запрещена явно — иначе `tests/contrast.spec.ts` краснеет по построению. Запрещена: см. правила ниже.

Для сравнения — то, что уходит: копирайт `white/40` на `#0a0a0a` давал 3.77:1 и проваливал AA; белый текст на `#c94a4a` давал 4.60:1, впритык.

### Правила применения

- `--muted` — только для текста от 14 px и мельче, несущего служебную роль (копирайт, сноска, подпись поля). Ни один смысловой текст не набирается этим уровнем.
- `--muted` **не ставится на `--raised`** — правило 2 контракта [design-tokens.md](./contracts/design-tokens.md). Числа выше и есть его основание; `tests/contrast.spec.ts` перебирает сочетания палитры, а не намерения, поэтому пара исключается из перебора явным списком.
- Прозрачности белого (`text-white/70` и прочие семь вариантов) удаляются из проекта. Уровень текста выбирается из трёх именованных.
- `--brass` на `--surface` и `--raised` допустим; `--brass-lt` предназначен для бликов и наведения, а не для протяжённого текста.
- Токен `lada-red` удаляется из конфигурации Tailwind вместе со всеми его употреблениями.

## Вертикальный ритм

Четыре ступени вместо одного `py-20 md:py-32` на всех секциях.

| Ступень | Значение | Где |
|---|---|---|
| `hero` | `min-height: 88svh` | первый экран |
| `air` | `clamp(6rem, 14vh, 11rem)` | повествовательные секции: «Про нас» |
| `work` | `clamp(4.5rem, 9vh, 7rem)` | рабочие секции: услуги, прайс, сертификаты |
| `tight` | `clamp(3rem, 6vh, 4.5rem)` | подвал, отбивки внутри секций |

## Что в модели не меняется

Прайс, тексты категорий, маршруты, метаданные и машиночитаемое описание — вне этой работы. Логотип остаётся файлом проекта исключительно как изображение организации в описании (`SeoHead.astro:120`), из вёрстки уходит везде.
