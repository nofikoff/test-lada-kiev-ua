# Research: Site voice and SEO copy

Все пункты проверены 2026-09-27 на ветке `004-site-voice` (от `main` 95d57b5).

## R1. Главный заголовок главной без нового шрифта (FR-015)

- **Decision**: `<h1>` первого экрана содержит два блока: бренд с прежним классом `display` и строку с прежним классом `hero__sub`. Отдельный `<p class="hero__sub">` исчезает. Промежуток между блоками повторяет прежний шаг сетки `.hero__in`: `h1` становится сеткой с `gap: inherit`.
- **Rationale**: бренд и строка набраны Cormorant (`display` и `.hero__sub` — `font-serif`, `tailwind.config.js` → `--font-cormorant`, `src/components/Hero.astro:234`), и оба начертания, прямое и курсив 300, уже загружаются первым экраном. Меняется текст, а не гарнитура или начертание; кириллическое подмножество уже запрошено прежней строкой «Майстерня масажу та краси». Набор файлов шрифтов первого экрана поэтому не меняется по построению; это проверяется сравнением запросов шрифтов до и после (quickstart.md §3).
- **Alternatives considered**: строка в `h1` визуально скрытым текстом — это и есть скрытый текст, FR-015 его запрещает; кириллица прямо в `display` — новый размер набора на критическом пути при запасе LCP 0.02 с (docs/specs/home-hero.md §Производительность).

## R2. Откуда `Service.name` (seo-contract.spec.ts:295)

- **Decision**: ничего не менять в генерации: `Service.name`, `OfferCatalog.name` и второй шаг `BreadcrumbList` берутся из `heading` frontmatter (`src/components/SeoHead.astro:191`), а `<h1>` страницы категории — из того же поля (`src/components/ServicePage.astro:52`).
- **Rationale**: новое `heading` с городом (FR-014) автоматически сохраняет равенство `Service.name = h1`, проверка 295 остаётся зелёной. Следствие, принимаемое сознательно: название шага в цепочке навигации тоже становится «Перманентний макіяж у Києві».
- **Alternatives considered**: отдельное поле `serviceName` без города — второе имя одной сущности, которое разойдётся с `h1` и потребует менять проверку.

## R3. Адрес сайта НУФВСУ (FR-018)

- **Decision**: `sameAs: "https://uni-sport.edu.ua/"`.
- **Rationale**: VERIFIED — сайт университета [uni-sport.edu.ua](https://uni-sport.edu.ua/) и запись вуза в [реестре ЕДЕБО](https://registry.edbo.gov.ua/university/180), поиск 2026-09-27.
- **Alternatives considered**: ссылка на Wikipedia — вторичный источник; без `sameAs` — FR-018 допускает, но адрес подтверждён.

## R4. Разметка FAQ (ADR об отказе)

- **Decision**: `FAQPage` не размечается.
- **Rationale**: VERIFIED ([Search Engine Journal](https://www.searchenginejournal.com/google-drops-faq-rich-results-from-search/574429/), [Search Engine Land](https://searchengineland.com/faq-schema-rise-fall-seo-today-463993)): в августе 2023 Google ограничил FAQ-сниппеты авторитетными государственными и медицинскими сайтами, с 7 мая 2026 не показывает их никому. Предположение spec подтвердилось в более сильной форме.
- **Alternatives considered**: разметить «на будущее» — ноль эффекта в выдаче, плюс вопросы-ответы, которых на сайте нет и которые пришлось бы сочинять.

## R5. `public/llms.txt` (FR-019)

- **Decision**: слов «майстерня/workshop» в файле нет (заголовок уже «Massage & Beauty Studio»). Дописываются две строки фактами из этого пакета: основательница (Lada Novikova, physical rehabilitation specialist, NUPESU graduate, leads massage sessions herself) и шугаринг в перечне депиляции. Файл входит в проверку единого названия.
- **Rationale**: файл пишется руками и расходится с разметкой молча (docs/specs/routes.md §Согласованность контактов); факт об основательнице теперь есть в JSON-LD и должен быть и здесь.
- **Alternatives considered**: не трогать — описание для языковых моделей осталось бы без человека, который теперь есть в разметке.

## R6. Хранение обращения (FR-004, FR-009)

- **Decision**: коллекция `about` — `glob({ pattern: '+(uk|ru|en).md', base: './src/content/about' })`, схема `heading`, `signatureName`, `signatureRole` (непустые, та же проверка видимого знака, что `translation`). Чтение — `aboutCopy(locale)` в `src/data/about.ts`, по образцу `serviceCopy`: нет записи → `throw new Error('нет обращения: src/content/about/<locale>.md')`.
- **Rationale**: многоабзацная проза — Markdown, короткие подписи — словарь (ADR-007); отсутствие файла ловится страницей, а не схемой, как у категорий (`src/data/services.ts`).
- **Alternatives considered**: строки `about.text1..N` в `ui.ts` — отвергнуто автором в brainstorming; `file()` с JSON — проза одной строкой с экранированием (ADR-007).

## R7. Подпись и раскладка секции

- **Decision**: `About.astro` выводит `heading` из записи в `SectionHeading`, `<Content />` в `.about__body[data-about-copy]`, затем прежнюю линию и подпись в абзаце `.about__close` («Лада Новикова, засновниця студії»). Первый абзац тела получает оформление `lede` селектором `:first-child` внутри тела.
- **Rationale**: `.about__close` — одно из двух мест, ради которых загружается курсив Cormorant (ADR-014, `src/components/About.astro`); подпись занимает его место вместо `text4`, и набор шрифтов ниже первого экрана тоже не меняется. `data-about-copy` ограничивает счёт слов телом обращения, как `data-service-copy` у категорий.
- **Alternatives considered**: подпись изображением-автографом — отвергнуто в brainstorming; подпись внутри `data-about-copy` — её слова считались бы телом обращения.

## R8. Проверки запросов (FR-020, FR-021)

- **Decision**: карта запросов — литералами в `tests/support/site.ts`: для каждой страницы список регулярных выражений с падежными формами; первое выражение — основное. Правила: все выражения находятся в `<title>`, `<h1>` и описании; основное начинается в первой половине описания; для категорий все выражения — в первом абзаце `[data-service-copy]`. `<title>` — `/ — Lada N$/` и длина ≤ 70.
- **Rationale**: литералы, а не импорт из `src/` (CLAUDE.md §Гейты); регулярные выражения принимают «Київ/Києві/Києва», которые буквальная строка не приняла бы.
- **Alternatives considered**: одна буквальная строка запроса — ломается на первом падеже; сравнение с `src/` — проверяет только непротиворечивость.

## R9. Строки фикстуры прежнего контента (FR-010)

- **Decision**: из `tests/fixtures/legacy-content.json` удаляются на каждом языке: подзаголовок первого экрана («Майстерня масажу та краси» и эквиваленты), заголовок и четыре абзаца «Про нас». Описание первого экрана (`hero.description`) остаётся, если его текст не меняется.
- **Rationale**: docs/specs/content-model.md §Фикстура прежнего контента — намеренная потеря отмечается правкой фикстуры тем же коммитом.
- **Alternatives considered**: заменить строки новыми — нарушает правило «новые строки в фикстуру не добавляются».

## R10. Перемер первого экрана (SC-004)

- **Decision**: Lighthouse 12.8.2, мобильный профиль, `--throttling-method=simulate`, прогретый `npm run preview` на 4329, два прогона на `/` и `/ru/` — та же процедура, что в docs/specs/home-hero.md §Производительность. Порог — 2.5 с; при превышении сокращается строка `hero.subtitle`.
- **Rationale**: единственная правка первого экрана — текст и вложенность `h1`; процедура базы уже описана, сравнение должно быть с ней.
