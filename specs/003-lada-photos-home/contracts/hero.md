# Contract: первый экран с портретом

Поправки к пакету 002: FR-011 → FR-007 этого пакета, FR-018 → FR-008. FR-017 из 002 (подложка под текстом не анимируется) сохраняется без изменений.

## Разметка и порядок

- В DOM `h1` и текстовая колонка идут раньше портрета. Над текстом на узком экране портрет ставит CSS `order`, разметка остаётся прежней.
- Портрет — `<picture>` с непустым `alt` из записи `role: 'portrait'`, без `aria-hidden`. Приоритет загрузки высокий (`priority`), `loading="lazy"` нет.
- Ширины 480/720/960/1440; `sizes="(min-width: 62rem) 40vw, 100vw"`.
- Монограммы в секции первого экрана нет.

## Раскладка

| Экран | Портрет | Текст | Проверка |
|---|---|---|---|
| ≥ 62rem | Колонка справа, 4:5, высота до 86vh, ширина ≤ 720 CSS px; левый и нижний край растворяются маской | Колонка слева на статичной подложке | Лицо не пересекает прямоугольник текстовой колонки |
| < 62rem, портретная ориентация | Блок сверху, высота — остаток после текста, ≤ ~55svh; лицо ниже фиксированной шапки | Под портретом | Кнопка звонка видна без прокрутки на 360×740 |
| Горизонтальная ориентация, малая высота | Сбоку, как на широком экране | Колонка слева | Портрет не увеличивает высоту первого экрана |
| 1366×768 | Как ≥ 62rem | Как ≥ 62rem | Кнопка звонка видна без прокрутки |

## Движение

- `wake` (1.8 с) и «дыхание» — на накрывающем слое в пределах рамки портрета. Прозрачность `<img>` и его обёрток не анимируется (research.md §R4).
- `drift` остаётся на рамке портрета.
- `prefers-reduced-motion: reduce` — ни одной действующей анимации (`reduced-motion.spec.ts` без изменений в методе).

## Машиночитаемое описание и превью

- `og:image` — результат `getImage` из портрета, 1200×630, JPEG; `og:image:width/height` — из результата. Вес ≤ 300 КБ: проверку уже держит `seo-contract.spec.ts`.
- JSON-LD `LocalBusiness.image` = `[logo, portrait]`, абсолютные адреса. Стокового кадра в выдаче нет.
