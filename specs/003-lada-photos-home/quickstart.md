# Quickstart: проверка фичи 003

## Автоматически

```sh
npm run check          # FR-020: недостающая строка ui.gallery.* или alt ломает типы/схему
npm run lint
npm run build          # схема коллекции gallery: пустой alt, чужая category, нет файла фото → сборка падает
npm run analyze        # SC-005: ≤ 1536 Б и ≤ 5 КБ на странице; код ленты засчитан, а не принят за аналитику
npx playwright test    # весь прогон, включая новые проверки ниже
```

## Вручную

1. **Lighthouse, мобильный профиль**, на `npm run preview`, страницы `/`, `/ru/`, `/en/`. Ожидается: доступность 100, производительность ≥ 95, LCP ≤ 2.5 с, CLS < 0.1 (SC-002, SC-003).
2. **Глазами**, на тех же трёх страницах:
   - лицо на портрете не срезано шапкой;
   - точки фокуса в карточках 21, 17, 06, 27 не режут лицо (FR-017);
   - край маски портрета не оставляет видимой границы.
3. **Превью после выкладки.** Вставить адрес главной в Telegram. На карточке должно быть лицо Лады. Кэш превью у Telegram, Facebook и Viber обновляется со своей задержкой, поэтому старая карточка в первые часы ошибкой не считается.

### Результат 2026-09-27

Lighthouse 12.8.2, мобильный профиль, `--throttling-method=simulate`, Chromium из Playwright, прогретый `npm run preview`, два прогона подряд:

| Адрес | Производительность | Доступность | Поиск | LCP | CLS |
|---|---|---|---|---|---|
| `/` | 96 | 100 | 100 | 2.48 с | 0–0.008 |
| `/ru/` | 96 | 100 | 100 | 2.48–2.52 с | 0–0.003 |
| `/en/` | 99 | 100 | 100 | 2.02 с | 0 |

До фичи было 97 / 97 / 99 при LCP 2.3 / 2.3 / 1.8 с. LCP на `/` и `/ru/` стоит на самом пороге SC-003. Разбор регрессии и что было сделано — research.md §R11.
